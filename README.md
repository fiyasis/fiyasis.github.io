# fiyasis.github.io

Landing page for **Fiyasis**, served via GitHub Pages.

- 🌐 Live: https://fiyasis.github.io
- 🏢 Company: https://www.fiyasis.com

## Local preview

Open `index.html` in a browser, or run:

```bash
python3 -m http.server 8080
```

then visit http://localhost:8080

## Deploy

Pushed to the `main` branch — GitHub Pages serves it automatically.
